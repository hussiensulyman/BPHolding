# BP Holding Premium Bilingual Platform

Production-oriented MVP foundation for BP Holding, a Saudi construction and engineering group delivering integrated solutions.

## Tech Stack

- Next.js 16 (App Router)
- TypeScript 5
- Tailwind CSS 4
- Prisma + PostgreSQL
- Auth.js (NextAuth v5 beta)
- next-intl (Arabic default + English)
- Vitest + Playwright

## Quick Start

```bash
npm install
cp .env.example .env
npm run db:generate
npm run db:migrate
npm run dev
```

## Core Scripts

- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run test:e2e`
