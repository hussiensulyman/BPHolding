# Delivery Phases

## Phase 1: MVP Foundation (Current)

- Next.js 16 + TypeScript + Tailwind baseline.
- Arabic-first i18n and RTL/LTR rendering.
- PostgreSQL schema bootstrap with Prisma.
- Auth/ImageKit integration scaffolding.
- Testing infrastructure with Vitest and Playwright.

## Phase 2: Core Business Features

- Portfolio and project showcase modules.
- RFQ workflow with attachments and lead capture.
- Careers and job application pipeline.

## Phase 3: Admin & Operations

- Role-based admin dashboard.
- Project and content CRUD.
- HR/store/community module foundation.

## Phase 4: Intelligence & Growth

- PEGN integrations.
- Chatbot support assistant.
- SEO expansion and analytics optimization.
