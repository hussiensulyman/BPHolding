# Commit Convention

## Required Format

```bash
git commit -m "type(scope): brief description" -m "• detail bullet 1
• detail bullet 2
• detail bullet 3"
```

## Allowed Types

- `feat`
- `fix`
- `docs`
- `style`
- `refactor`
- `perf`
- `test`
- `chore`

## Allowed Scopes

- `auth`
- `i18n`
- `rtl`
- `portfolio`
- `rfq`
- `careers`
- `admin`
- `hr`
- `store`
- `pegn`
- `community`
- `chatbot`
- `seo`
- `db`
- `imagekit`
- `ui`
- `forms`
- `init`

## Example

```bash
git commit -m "feat(i18n): add Arabic-first locale routing" -m "• add next-intl middleware and route prefixes
• inject html dir for rtl/ltr rendering
• move homepage text into locale dictionaries"
```
